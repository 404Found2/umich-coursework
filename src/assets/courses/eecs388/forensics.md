# Forensics

Project 5 of EECS 388. Acting as a forensic analyst, my partner and I investigate a disk image
from a suspect's computer, recover evidence, and write a report making the case for guilt or
innocence.

> This project is released near the end of the semester. I'll update this page once I've
> completed it. The course has a strict no-leaks policy, so this page will stay high-level.

## Overview

- **Analyze a disk image** without booting its operating system, to preserve forensic integrity
- **Recover evidence:** find files and other traces of the suspect's activity
- **Document findings** in a written report and submit the supporting evidence

## What I Expect to Learn

- Forensic techniques for investigating computer misuse and intrusions
- Why computer use leaves persistent traces that are hard to remove or hide
- Using Autopsy and related tools to examine file systems
- Writing a clear, evidence-based report
