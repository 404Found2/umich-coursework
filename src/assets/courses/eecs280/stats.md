# Statistics

Project 1 of EECS 280. A C++ program that reads a dataset, computes descriptive statistics,
and performs a two-sample analysis comparing two groups in the data.

## Overview

Statistical analysis underlies fields from medicine to machine learning. This project
implements a small statistics library and uses it to analyze real data.

## Features

- [x] Descriptive statistics: sum, mean, median, standard deviation, and percentiles
- [x] Filtering data into two groups for comparison
- [x] Two-sample analysis comparing the groups
- [x] Unit tests for every function in the statistics library

## What I Learned

- **C++ fundamentals:** types, control flow, and `std::vector`
- **Procedural abstraction:** implementing functions against written interface specs
- **Unit testing:** writing tests for every library function, not just checking the final output
- **The C++ toolchain:** compiling with `make`, using a visual debugger, and submitting to an autograder
- **Translating math to code:** adapting formulas written with 1-based indices to 0-based vectors
