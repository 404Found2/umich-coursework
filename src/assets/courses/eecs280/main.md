# EECS 280: Programming and Introductory Data Structures

EECS 280 covers computer science fundamentals through C++. Over six projects I built a
statistics tool, a content-aware image resizer, a Euchre card game, a machine learning
classifier, a terminal text editor, and a map backed by a binary search tree. Along the way the
course moves from procedural programming to object-oriented design, dynamic memory, and recursion.

## What I Learned

### C++ and the machine model

- How C++ programs use memory: the stack, the heap, and object lifetimes
- Pointers, references, and arrays, including pointer arithmetic and C-style strings
- Procedural abstraction and writing functions against an interface (RME comments:
  requires, modifies, effects)

### Abstract data types and object-oriented programming

- C-style ADTs with structs, then C++ classes with encapsulation and invariants
- Derived classes, inheritance, and **polymorphism** with virtual functions
- Templates and generic containers

### Containers and dynamic memory

- Array-based and sorted containers, plus an introduction to time complexity
- Dynamic memory with `new` and `delete`, and **RAII**
- Deep copies and **the Big Three**: the destructor, copy constructor, and assignment operator
- Linked lists, iterators, and functors

### Recursion and trees

- Recursion, tail recursion, and structural recursion
- Binary search trees, sets, and maps
- Error handling with exceptions

### Software engineering practice

- Unit testing and test-driven development
- Debugging with a visual debugger
- Version control with Git, and working with a partner
